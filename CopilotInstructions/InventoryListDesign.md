# 在庫一覧画面 設計書

## 概要
在庫一覧画面は、冷蔵庫内のすべての食材アイテムを一覧表示し、検索・フィルタリング・ソート機能を提供する画面です。ダッシュボードの「もっと見る」リンクから遷移します。

## 対象範囲
- すべての在庫アイテムを一覧表示
- カテゴリ別フィルタリング
- 検索機能
- ソート機能（数量順、追加日時順、名前順）
- アイテムの編集・削除

## 利用者ゴール
- 冷蔵庫の全在庫を確認する
- 特定のアイテムを素早く検索する
- カテゴリやソート条件で在庫を整理して確認する
- アイテムの情報を編集・削除する

## 画面構成

### ヘッダー
- タイトル: 「在庫一覧」
- 戻るボタン（ダッシュボードへ）
- 検索ボタン

### 検索バー
- テキスト入力フィールド
- プレースホルダー: 「食材名で検索」
- クリアボタン

### フィルタ・ソートバー
- カテゴリフィルタボタン
  - すべて
  - 野菜類
  - 肉類
  - 乳製品
  - 調味料
  - その他
- ソートボタン
  - 追加日時順（デフォルト）
  - 名前順（あいうえお順）
  - 数量順（多い順/少ない順）

### 在庫リスト
- 各在庫アイテムカード
  - アイテム名（大）
  - カテゴリ / サブカテゴリ
  - 数量と単位
  - 更新日
  - 操作ボタン
    - 編集ボタン
    - 削除ボタン

### アイテム詳細（モーダルまたはダイアログ）
- アイテムの完全な情報
  - 入出庫タイプ
  - 大分類・小分類
  - 名称
  - 数量・単位
  - 登録日
  - 更新日
- 編集フォーム
- 削除確認ダイアログ

## データモデル

### FridgeItem（再掲）
```typescript
interface FridgeItem {
  id: string;
  type: ItemType; // 入庫/出庫
  category: string; // 大分類
  subCategory: string; // 小分類
  name: string; // 名称
  quantity: number; // 数量
  unit: string; // 単位
  updatedAt: Date; // 更新日
}
```

### Filter & Sort
```typescript
interface InventoryFilter {
  category?: string;
  searchQuery?: string;
  sortBy: 'name' | 'quantity' | 'updatedAt';
  sortOrder: 'asc' | 'desc';
}
```

## API

### 在庫一覧取得
```
GET /api/fridge/items
Query Parameters:
  - category: string (optional)
  - search: string (optional)
  - sortBy: 'name' | 'quantity' | 'updatedAt' (default: 'updatedAt')
  - sortOrder: 'asc' | 'desc' (default: 'desc')
  - page: number (default: 1)
  - limit: number (default: 20)

Response:
{
  items: FridgeItem[];
  totalCount: number;
  currentPage: number;
  totalPages: number;
}
```

### アイテム詳細取得
```
GET /api/fridge/items/{id}

Response:
FridgeItem
```

### アイテム更新
```
PUT /api/fridge/items/{id}
Body:
FridgeItem

Response:
FridgeItem
```

### アイテム削除
```
DELETE /api/fridge/items/{id}

Response:
{
  success: boolean;
  message: string;
}
```

## UI/UX

### レイアウト
- フルスクリーン表示
- スクロール可能なリスト
- プルトゥリフレッシュ対応
- 無限スクロール（ページネーション）

### インタラクション
- タップでアイテム詳細を表示
- 長押しでコンテキストメニュー表示（編集/削除）
- スワイプジェスチャーで削除（オプション）
- 検索入力時のリアルタイムフィルタリング

### 空状態
- 在庫がない場合
  - メッセージ: 「在庫がありません」
  - 「食材を追加」ボタン
- 検索結果が0件の場合
  - メッセージ: 「検索条件に一致する食材がありません」
  - 検索をクリアするボタン

### カード表示オプション
- リスト表示（デフォルト）
- グリッド表示（オプション）
- コンパクト表示（オプション）

## 非機能要件
- 表示速度: 初回ロード < 500ms
- 検索レスポンス: < 100ms
- スクロール性能: 60fps維持
- メモリ使用量: 仮想スクロール実装で最適化
- オフライン対応: キャッシュからの表示・編集

## テストケース
- 在庫が正しくソートされて表示される
- カテゴリフィルタが正しく動作する
- 検索機能が正しく動作する
- ページネーションが正しく動作する
- アイテムの編集が正常に完了する
- アイテムの削除が正常に完了する
- 削除確認ダイアログが表示される
- プルトゥリフレッシュでデータが更新される
- 空状態が適切に表示される

## 実装上の注意点
- 大量データの効率的な表示（仮想スクロール）
- 検索のデバウンス処理（300ms）
- フィルタ・ソート条件の永続化（ローカルストレージ）
- 楽観的UI更新（Optimistic UI）
- エラーハンドリング（ネットワークエラー、バリデーションエラー）
- 削除の取り消し機能（Undo）
- バッチ操作（複数選択による一括削除等）
