# 在庫履歴画面設計書

## 概要
冷蔵庫の中身の増減履歴を確認するための画面です。食材の入庫・出庫の履歴を時系列で確認でき、家計簿の収支管理のような形で在庫の変動を把握できます。

## 画面構成

### 1. タブ構成
- **減った分タブ**（デフォルト表示）
  - 食材の消費・使用履歴を表示
  - 出庫操作による減少記録
- **増えた分タブ**
  - 食材の購入・追加履歴を表示
  - 入庫操作による増加記録

### 2. 月次表示機能
- **月選択ナビゲーション**
  - 左矢印ボタン：前月表示
  - 現在月表示（例：「2024年10月」）
  - 右矢印ボタン：翌月表示
- **表示範囲**
  - 選択した月の1日〜末日の履歴を表示
  - データがない月は空の状態を表示

### 3. 階層表示構造

#### 第1階層：大分類一覧
```
📂 肉類 (15件)
📂 野菜類 (32件)
📂 乳製品 (8件)
📂 調味料 (5件)
📂 飲料 (12件)
...
```

**表示項目：**
- 大分類名
- 該当月の増減件数
- 展開/折りたたみ状態

#### 第2階層：小分類一覧（大分類タップ時）
```
📂 肉類 (15件)
  └ 牛肉 (6件)
  └ 豚肉 (4件)
  └ 鶏肉 (3件)
  └ ハム・ベーコン (2件)
```

**表示項目：**
- 小分類名
- 該当月の増減件数
- 詳細表示への遷移ボタン

#### 第3階層：詳細履歴（小分類タップ時）
```
牛肉の履歴 - 2024年10月

10/15 牛ステーキ肉 -200g    [編集]
10/12 牛こま切れ肉 +300g    [編集]
10/08 牛ひき肉 -150g        [編集]
10/05 牛もも肉 +500g        [編集]
...
```

**表示項目：**
- 増減日（MM/DD形式）
- 食材名
- 増減量（+/-付きで表示）
- 単位
- 編集ボタン（各履歴項目に配置）

#### 第4階層：履歴編集（編集ボタンタップ時）
```
履歴を編集 - 牛ステーキ肉

日付：    [2024/10/15 ▼]
食材名：  [牛ステーキ肉        ]
増減：    [減少 ▼] [200] [g ▼]

┌────────┬────────┐
│  削除  │  保存  │
└────────┴────────┘
```

**編集可能項目：**
- 日付（日付ピッカー）
- 食材名（テキスト入力）
- 増減タイプ（増加/減少のドロップダウン）
- 数量（数値入力）
- 単位（ドロップダウン）

## データ表示仕様

### 1. ソート順
- **日付順**：新しい日付から古い日付へ（降順）
- **大分類順**：アプリ内で定義された順序
- **小分類順**：50音順

### 2. 件数表示
- 各階層で該当する履歴件数を括弧内に表示
- 件数が0の場合は分類自体を非表示

### 3. 色分け
- **増加（+）**：緑色（#28a745）
- **減少（-）**：赤色（#dc3545）
- **日付**：グレー色（#6c757d）

## 技術仕様

### 1. 必要なエンティティ

#### HistoryRecord（履歴記録）
```typescript
interface HistoryRecord {
  id: string;
  fridgeItemId: string;
  changeType: 'increase' | 'decrease';
  changeAmount: number;
  date: Date;
  category: string;
  subCategory: string;
  itemName: string;
  unit: string;
}
```

### 2. 必要なユースケース

#### GetHistoryUseCase
```typescript
interface GetHistoryUseCase {
  getMonthlyHistory(
    year: number, 
    month: number, 
    changeType?: 'increase' | 'decrease'
  ): Promise<HistoryRecord[]>;
  
  getHistoryByCategory(
    year: number,
    month: number,
    category: string,
    subCategory?: string,
    changeType?: 'increase' | 'decrease'
  ): Promise<HistoryRecord[]>;
}
```

#### UpdateHistoryUseCase（履歴編集用）
```typescript
interface UpdateHistoryUseCase {
  updateHistory(
    historyId: string,
    updateData: {
      date?: Date;
      itemName?: string;
      changeType?: 'increase' | 'decrease';
      changeAmount?: number;
      unit?: string;
    }
  ): Promise<void>;
  
  deleteHistory(historyId: string): Promise<void>;
}
```

### 3. 画面遷移
1. **履歴画面（一覧）** ← デフォルト表示
2. **履歴画面（詳細）** ← 小分類タップ時
3. **履歴編集画面** ← 編集ボタンタップ時

### 4. 状態管理
- 選択中のタブ（増加/減少）
- 選択中の年月
- 展開中の大分類一覧
- 詳細表示中の小分類情報
- 編集中の履歴データ

## 履歴編集機能の詳細仕様

### 1. 編集可能項目
- **日付**: 日付ピッカーによる選択
- **食材名**: 自由テキスト入力
- **増減タイプ**: 増加/減少の選択
- **数量**: 正の数値のみ入力可能
- **単位**: 定義済み単位からの選択

### 2. バリデーションルール
- **日付**: 未来日は選択不可
- **食材名**: 空白不可、50文字以内
- **数量**: 0より大きい数値、小数点以下2桁まで
- **単位**: 定義済みリストから選択必須

### 3. 操作フロー
1. 詳細履歴画面で編集ボタンをタップ
2. 編集画面がモーダル表示
3. 各項目を編集
4. 「保存」ボタンで更新実行
5. 「削除」ボタンで履歴削除
6. 「×」ボタンで編集キャンセル

### 4. 削除時の確認
